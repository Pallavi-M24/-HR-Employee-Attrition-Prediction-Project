# HR Employee Attrition Prediction

## Project Overview

This project focuses on predicting employee attrition (whether an employee will leave the company or stay) using machine learning techniques. The goal is to help HR departments identify employees at risk of leaving and support data-driven retention strategies.

The project also includes data visualization and explainability using SHAP and Power BI.

## Objective

To build a predictive system that analyzes employee data and identifies key factors influencing attrition, enabling better HR decision-making.

## Tools and Technologies Used

* NumPy
* Scikit-learn
* Matplotlib

* Power BI

## Project Workflow

1. Data collection (HR attrition dataset)
2. Data preprocessing (handling categorical variables using Label Encoding)
3. Exploratory data analysis (EDA)
4. Feature selection
5. Train-test split
6. Model building (Random Forest Classifier)
7. Model evaluation (accuracy and confusion matrix)
8. Model explainability using SHAP
9. Data visualization using Power BI

## Machine Learning Model

* Algorithm used: Random Forest Classifier
* Accuracy achieved: approximately 85%

 ## Results
- Model Accuracy: **85%**
- Confusion Matrix used for evaluation
- SHAP Explainability for feature interpretation

## Key Insights

* Employees working overtime are more likely to leave the company
* Monthly income is a strong factor influencing attrition
* Employees with fewer years at the company show higher attrition risk
* Age and job role also influence attrition
